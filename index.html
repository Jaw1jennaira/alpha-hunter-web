Chain: Solana Mainnet

Tanda tangan tes ini hanya membuktikan wallet kamu bekerja dengan Seed Vault. Mint/claim project tetap dieksekusi lewat portal project masing-masing di v1.

Tentang Alpha Hunter

Alpha Hunter adalah pendamping hunter untuk HP Solana Seeker: memberi tahu kamu saat ada early project, free mint, airdrop, dan whitelist, lalu membantu kamu sign langsung dari HP.

Data

Cara kerja v1

  • Feed berisi snapshot data hunter saat aplikasi dibuat. Refresh data = update aplikasi berikutnya (backend menyusul).
  • Solana: sign via Seed Vault + Mobile Wallet Adapter.
  • EVM: sign via WalletConnect ke wallet kamu sendiri (butuh Project ID — lihat tab Wallet).
  • Chain tanpa wallet (mis. Ink): aplikasi menampilkan status + panduan, dan tetap memberi notifikasi.

Aturan keamanan

  • Gratis + audit GO → bisa langsung sign.
  • Berbayar / audit CAUTION → minta persetujuan kamu dulu di aplikasi.
  • Tidak ada auto-sign. Tidak ada seed phrase. Tidak ada kunci yang disimpan.
